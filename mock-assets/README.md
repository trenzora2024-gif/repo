# Studio renders (generated, temporary)

Generated by `npm run visuals:render` from the locked masters in `artwork/masters/` (placed whole, uniformly scaled; never edited). Renders, not photographs.

- `mock-assets/visuals/products/`: product images for the mock storefront and preview only. Never in the production build.
- `public/visuals/editorial/`: homepage/design-page imagery that ships with the site until photography replaces it.

Replacement plan: `catalogue/image-replacement-map.csv`, docs/GRAPHICS-ROADMAP.md.
