# Production masters

Put the **official Trenzora production master pack** here, exactly as supplied:

```
01_mumbai_made.png        06_us.png
02_local_life.png         07_pet_parent.png
03_corporate_survivor.png 08_campus_energy.png
04_coffee_personality.png 09_desi_roots.png
05_bestie_energy.png      10_make_it_yours.png
```

Then run `npm run verify:artwork`.

- These are supplier print files, not mockups. Never replace them with AI-generated or placeholder art.
- No moodboards in this folder.
- The PNGs are gitignored, so large binaries and unreleased IP stay out of git history. The checksums are recorded in `catalogue/artwork-manifest.json`.
